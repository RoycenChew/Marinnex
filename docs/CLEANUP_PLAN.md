## 6. NOT delete-candidates, despite tool output

Recorded so the same ground is not re-covered later.

- **26 "unused functions" in `api/routers/*`** — FastAPI handlers, bound by
  decorator.
- **`tesseract_or_skip` in `test_scan_safety.py`** — a pytest fixture, injected
  by name.
- **`formatMoney`, `MATCH_META`, `STATUS_META`, `PROCESSING_STEPS`,
  `FIELD_STATUS`, `ERROR_COPY`, and ~12 more** — knip calls these "unused
  exports", but each **is** used inside its own module. The dead thing is the
  `export` keyword, not the code. Removing the keyword is cosmetic and risks a
  merge conflict for no behavioural gain. **Recommend leaving them.**
- **`web/public/mockServiceWorker.js`** — loaded by URL at runtime.
- **`Dockerfile` / `docker-compose.yml`** — unused today, but they are the
  Phase 4 deployment plan and `README_RUN.md` documents them.
