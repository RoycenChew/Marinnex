# MARINNEX LAB ENTERPRISE UX QUALITY GATE

Use this document after implementation.

## 1. Product clarity

A first-time user can explain what Marinnex Lab does without assistance.

## 2. Navigation

Users can quickly find:

- Documents
- Guide
- API
- API Keys
- Help

## 3. Document processing

Users understand:

- upload
- processing
- completion
- failure
- retry

## 4. Extraction

Users can distinguish:

- extracted value
- confidence
- needs review
- verified value

## 5. Source traceability

If supported by the backend, fields can be traced to their document source.

## 6. Trust

No unsupported claims are displayed.

## 7. Accessibility

Check:

- keyboard navigation
- focus
- labels
- contrast
- semantic elements
- screen reader states
- reduced motion

## 8. Responsive

Test:

- 1440px desktop
- 1280px laptop
- 1024px tablet
- 768px tablet
- 390px mobile

## 9. Error handling

Every important operation has:

- loading
- success
- empty
- error
- retry

## 10. Performance

Animations must not materially degrade:

- page load
- interaction
- scrolling
- document processing UX

## 11. Design consistency

No random:

- button styles
- radii
- spacing
- colors
- typography
- icon styles

## 12. Enterprise readiness

The interface should feel suitable for a real business workflow rather than
a hackathon prototype.

## Final question

Would a finance employee trust this interface enough to process a real document?

If not, identify exactly why and fix it.
