# Marinnex Document Flow Animation

This folder contains a standalone animation prototype.

## What it demonstrates

Financial document
→ AI reading
→ extracted fields
→ confidence
→ human review
→ structured JSON

## Use in the real website

Recommended options:

### React

Convert the HTML structure into a React component and move styles into your
existing design system.

### Framer Motion

If the project already uses Framer Motion, use it for:
- field entrance
- scan movement
- state transitions
- reduced motion

### CSS only

For a lightweight homepage hero, CSS animations are enough.

## Important

The prototype is a visual concept. Replace example document values with the
actual schema supported by the Marinnex backend.

Do not present example fields as guaranteed capabilities.
